* DESCRIPCION DEL PROYECTO

Appsaslon es un sistema web tipo aplicacion full_stack 
que sirve para el gestionamiento de un salon de belleza , perimite a los usuarios , agendar citas
gestionar servicicios y visualizar precios 


* TECNOLOGIAS UTILIZADAS

* Backend: PHP 8.x con arquitectura MVC (Modelo-Vista-Controlador).
* Framework: Laravel 11 
* Base de Datos: MySQL , integrado con xampp 
* Frontend: visual studio como herramienta para editar
* Autenticación: Laravel Breeze / Sistema de Login personalizado.

  
  * INSTALACION 
  
  * lo primero es instalar el composer y crear un nuevo proyecto
  * una vez se tenga el proyecto se ejecutan las migraciones de las tablas 
  * se instala laravel brezze para las vistas responsive y aplicar el css
  * configurar la base de datos y iniciar el servidor 


 * FUNCIONALIDADES 

 * Registro y Login: Autenticación segura para usuarios.
 * Gestión de Servicios (CRUD): El administrador puede crear, leer, actualizar y eliminar servicios.
 * Agendamiento de Citas: Interfaz intuitiva para seleccionar fecha y hora de la cita.
 * Panel de Administración: Resumen de las citas programadas por día.
 * Validaciones en Tiempo Real: Control de datos tanto en cliente como en servidor.
